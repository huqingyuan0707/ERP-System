# B-01～B-05 修复与验收记录

## 范围

本次修复现有基础资料、关联库存与导入导出中的确定缺陷。没有扩建完整采购、销售、出入库、财务、B-06 员工模块。代码未提交、未推送、未部署；未操作已有业务数据库。

## 已修复

- 可信租户来自已认证账号；请求头不能切换租户，非法头受控返回 400，不一致返回 403。
- 商品、分类、单位查询、查重、关联、统计、导入导出按租户隔离。
- 供应商缺失 AsyncSession 导入，部署版 Python 可正常加载。
- 名称和条码先规范化；Decimal 严格校验；必填业务字段显式 null 返回 422；软删除编码继续占用并返回 409。
- 活动非空条码、根分类名称增加租户内数据库唯一约束；冲突不再变成未处理的 500。
- 显式幂等键替代自动编码共用 24 小时标记，支持正常连续新增、重放、失败重试、过期和异参冲突；业务、成功审计和缓存结果同事务。
- 导入复用商品规则，非法数值不再归零；错误定位原行和字段；整批原子提交；分类路径及歧义检查。
- 模板数据与说明分离，兼容精确旧说明行，中文文件名正常编码；不再默认上传空 action。
- 商品和库存分批完整导出，不再静默截断 10,000 条；任务与下载按租户、归属和权限统一校验；前端轮询终止与有限重试。
- 仓库负责人按租户校验并提供最小选项接口；保留用户外键，明确员工模块尚未接入。
- 仓库备注保留，客户／供应商地址和备注分别传输；只读状态显示修正。
- 库存写入校验商品、仓库和单位归属／状态／数量精度；历史锁定释放不因停用而一刀切阻断。
- 商品删除逐仓检查账面和锁定库存；商品修改／删除与库存共用商品行锁；单位降精度不反向锁商品，避免已识别的锁顺序循环。
- 客户额度 0 表示不限；block/warn/off 分别阻断、警告、放行，摘要与前端一致。
- 基础资料及导入导出操作日志补操作者、租户、请求元数据和脱敏；失败不留下成功日志。
- 测试不读取开发 .env，不继承业务数据库连接，默认使用本次新建临时 SQLite；真实租户依赖不再被固定租户覆盖。

## 数据库升级注意

当前工作树新增两个连续 Alembic 版本：

- `f2b6c8d0e1a3` 接在 `e4a8b7c6d5f4` 后，处理基础资料安全约束及审计／任务租户列。
- `d4e9a1b7c3f5` 接在 `f2b6c8d0e1a3` 后，是当前 head，幂等补齐库存、报表、对账单导出权限及各租户有效 admin 授权。

- 操作日志及任务增加可空 tenant_id；历史未知归属保持未知，不默认放入租户 1，普通租户不可见。
- 活动条码重复、非规范条码（首尾空白／纯空白）、分类非规范名称或根分类冲突会在迁移前实际抛出异常阻断；全部检查在 DDL 前完成并列出 ID。
- 不自动 trim、删数据、改码、改归属或舍入历史库存；跨租户关联与数值异常仅报告，需明确人工处置。
- 导出权限迁移不覆盖或删除历史权限；若存在历史重复权限码，选择最小 ID 作为新增 admin 授权的规范行，重复执行不新增权限或授权。
- 已有数据库版本落后时启动会明确拒绝，不再把未执行的迁移 stamp 成成功；完全空库才执行真实 `alembic upgrade head`。
- 已有库应先备份并在测试副本验证，再显式执行 `alembic upgrade head`。本次没有对已有库执行该命令。

逐条核验与源码／测试证据见 [AI评审整改说明](./AI评审整改说明.md)。本记录只保留与整改、测试和 CI 有关的结论：

- `ExportButton` 的模板绑定未使用 `void`；脚本中的 `void Promise` 是合法 TypeScript，已有 type-check、ESLint 和构建记录。
- “逐行中文注释”没有对应可执行检查，本轮按周围代码风格保留用途说明及关键事务／安全原因注释，不为泛化告警批量添加机械注释。
