# 定时任务配置指南

本文档说明如何配置ERP系统的定时任务，包括过期数据清理等维护任务。

## 定时任务概述

系统需要定期清理过期数据以保持数据库性能和数据整洁。当前支持的定时任务：

1. **幂等键清理** - 清理过期的幂等键记录，防止表无限增长
2. **操作日志清理** - 清理超过保留期限的操作日志，保持日志表大小合理

## 幂等键清理任务

### 任务说明

- **目标**：清理 `idem_idempotency_key` 表中已过期的记录
- **执行频率**：建议每天凌晨执行一次
- **风险等级**：低 - 只删除已过期的记录，不影响业务数据

### 实现方式

#### 方式1：直接运行脚本（测试环境）

```bash
cd backend
python scripts/cleanup_expired_idempotency.py
```

#### 方式2：Cron定时任务（Linux/生产环境）

编辑crontab：
```bash
crontab -e
```

添加以下行（每天凌晨2点执行）：
```cron
0 2 * * * cd /path/to/erp/backend && python scripts/cleanup_expired_idempotency.py >> /var/log/erp/cleanup.log 2>&1
```

#### 方式3：Celery Beat（推荐 - 如果项目使用Celery）

在 `backend/app/tasks.py` 中添加Celery任务：

```python
from celery import shared_task
from app.db.session import async_session_maker
from app.services.maintenance import MaintenanceService

@shared_task
def cleanup_expired_idempotency_keys():
    """Celery定时任务：清理过期的幂等键。"""
    import asyncio

    async def _cleanup():
        async with async_session_maker() as db:
            maintenance = MaintenanceService(db)
            result = await maintenance.cleanup_expired_idempotency_keys()
            return result

    return asyncio.run(_cleanup())
```

在 `celeryconfig.py` 中配置定时任务：

```python
from celery.schedules import crontab

beat_schedule = {
    'cleanup-idempotency-keys': {
        'task': 'app.tasks.cleanup_expired_idempotency_keys',
        'schedule': crontab(hour=2, minute=0),  # 每天凌晨2点
    },
}
```

#### 方式4：APScheduler（推荐 - 轻量级定时任务）

在 `backend/app/main.py` 中添加：

```python
from apscheduler.schedulers.asyncio import AsyncIOScheduler
from app.services.maintenance import MaintenanceService

scheduler = AsyncIOScheduler()

@scheduler.scheduled_job('cron', hour=2, minute=0)
async def cleanup_job():
    """每天凌晨2点执行幂等键清理。"""
    async with async_session_maker() as db:
        maintenance = MaintenanceService(db)
        result = await maintenance.cleanup_expired_idempotency_keys()
        print(f"幂等键清理完成，删除记录数: {result['deleted_count']}")

# 在应用启动时启动调度器
@app.on_event("startup")
async def startup_event():
    scheduler.start()

# 在应用关闭时停止调度器
@app.on_event("shutdown")
async def shutdown_event():
    scheduler.shutdown()
```

### 监控建议

1. **日志记录**：记录每次清理的删除数量和执行时间
2. **告警设置**：如果删除数量异常（如超过1000条），发送告警
3. **定期检查**：通过 `get_idempotency_stats()` 方法监控表大小

## 操作日志清理任务

### 任务说明

- **目标**：清理 `sys_oper_log` 表中超过保留期限的记录
- **执行频率**：建议每周执行一次
- **风险等级**：低 - 只删除超过保留期限的历史日志，不影响近期数据
- **默认保留期限**：90天

### 实现方式

#### 方式1：直接运行脚本（测试环境）

```bash
cd backend
python scripts/cleanup_data.py
```

该脚本会同时执行幂等键清理和操作日志清理。

#### 方式2：Cron定时任务（Linux/生产环境）

添加以下行到crontab：
```cron
# 每天凌晨2点清理幂等键
0 2 * * * cd /path/to/erp/backend && python scripts/cleanup_data.py >> /var/log/erp/cleanup.log 2>&1

# 每周日凌晨3点清理操作日志（如果需要单独清理）
0 3 * * 0 cd /path/to/erp/backend && python -c "
import asyncio
import sys
sys.path.insert(0, '/path/to/erp/backend')
from app.db.session import async_session_maker
from app.services.maintenance import MaintenanceService

async def cleanup_logs():
    async with async_session_maker() as db:
        maintenance = MaintenanceService(db)
        result = await maintenance.cleanup_old_oper_logs(retention_days=90)
        print(f'删除操作日志: {result[\"deleted_count\"]}条')

asyncio.run(cleanup_logs())
" >> /var/log/erp/cleanup.log 2>&1
```

#### 方式3：Celery Beat（推荐 - 如果项目使用Celery）

在 `backend/app/tasks.py` 中添加：

```python
@shared_task
def cleanup_old_oper_logs(retention_days: int = 90):
    """Celery定时任务：清理过期的操作日志。"""
    import asyncio

    async def _cleanup():
        async with async_session_maker() as db:
            maintenance = MaintenanceService(db)
            result = await maintenance.cleanup_old_oper_logs(retention_days=retention_days)
            return result

    return asyncio.run(_cleanup())
```

在 `celeryconfig.py` 中配置：

```python
beat_schedule = {
    'cleanup-idempotency-keys': {
        'task': 'app.tasks.cleanup_expired_idempotency_keys',
        'schedule': crontab(hour=2, minute=0),  # 每天凌晨2点
    },
    'cleanup-oper-logs': {
        'task': 'app.tasks.cleanup_old_oper_logs',
        'schedule': crontab(hour=3, minute=0, day_of_week=0),  # 每周日凌晨3点
        'args': (90,),  # 保留90天
    },
}
```

#### 方式4：APScheduler（推荐 - 轻量级定时任务）

在 `backend/app/main.py` 中添加：

```python
@scheduler.scheduled_job('cron', hour=2, minute=0)
async def cleanup_idempotency_job():
    """每天凌晨2点执行幂等键清理。"""
    async with async_session_maker() as db:
        maintenance = MaintenanceService(db)
        result = await maintenance.cleanup_expired_idempotency_keys()
        print(f"幂等键清理完成，删除记录数: {result['deleted_count']}")

@scheduler.scheduled_job('cron', hour=3, minute=0, day_of_week=0)
async def cleanup_oper_logs_job():
    """每周日凌晨3点执行操作日志清理。"""
    async with async_session_maker() as db:
        maintenance = MaintenanceService(db)
        result = await maintenance.cleanup_old_oper_logs(retention_days=90)
        print(f"操作日志清理完成，删除记录数: {result['deleted_count']}")
```

### 监控建议

1. **日志记录**：记录每次清理的删除数量和执行时间
2. **告警设置**：如果删除数量异常（如超过10000条），发送告警
3. **定期检查**：通过 `get_oper_log_stats()` 方法监控表大小
4. **保留策略**：根据业务需求调整保留期限（默认90天）

### 手动执行清理示例

```python
from app.db.session import async_session_maker
from app.services.maintenance import MaintenanceService

async def manual_cleanup():
    async with async_session_maker() as db:
        maintenance = MaintenanceService(db)

        # 清理幂等键
        idem_result = await maintenance.cleanup_expired_idempotency_keys()
        print(f"幂等键清理结果: {idem_result}")

        # 清理操作日志（保留90天）
        log_result = await maintenance.cleanup_old_oper_logs(retention_days=90)
        print(f"操作日志清理结果: {log_result}")

        # 获取所有统计
        all_stats = await maintenance.get_all_stats()
        print(f"系统统计: {all_stats}")
```

## 其他定时任务建议

未来可能需要添加的定时任务：

1. **操作日志归档** - 定期归档历史操作日志到冷存储
2. **登录日志清理** - 清理超过保留期限的登录日志
3. **软删除数据清理** - 清理超过一定时间的软删除数据（需谨慎）
4. **库存快照生成** - 定期生成库存快照用于数据分析

## 注意事项

1. **备份**：在执行任何清理任务前，确保有数据库备份
2. **测试**：先在测试环境验证定时任务配置
3. **监控**：监控定时任务的执行状态和结果
4. **文档**：记录定时任务的变更历史
