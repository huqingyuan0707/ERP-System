# 企业ERP系统 · 数据库表设计（V1.0）

- 数据库：PostgreSQL 16；主键 `id bigserial`
- 命名：模块前缀_业务名，小写下划线；金额 `numeric(18,2)`，数量 `numeric(18,4)`，时间 `timestamptz`
- 逻辑删除 `is_deleted`；并发 `version int`

## 公共字段（业务表通用，下表不再重复）
id / created_at / created_by / updated_at / updated_by / is_deleted / remark

## 1. 系统管理
- **sys_user 用户**：username(唯一) / password_hash / real_name / mobile / email / dept_id / position / status(1启用0禁用) / last_login_at / last_login_ip
- **sys_dept 部门**：name / parent_id / leader / sort / status
- **sys_role 角色**：code(唯一) / name / data_scope(1本人2本部门3全部) / status
- **sys_user_role**：user_id / role_id
- **sys_permission 权限(目录/菜单/按钮)**：parent_id / name / type(1目录2菜单3按钮) / perm_code / route_path / component / icon / sort
- **sys_role_permission**：role_id / permission_id
- **sys_role_dept 数据范围**：role_id / dept_id
- **sys_oper_log**：user_id / module / action / method / url / ip / params / result / duration_ms / status
- **sys_login_log**：user_id / ip / ua / status / message
- **sys_dict_type / sys_dict_item**：code / name；type_code / label / value / sort
- **sys_config**：config_key / config_value / name（公司信息、单据编号规则）

## 2. 基础资料
- **bd_goods_category**：name / parent_id / sort
- **bd_unit**：name / precision
- **bd_goods 商品**：code(唯一) / name / category_id / spec / unit_id / barcode / cost_price / sale_price / stock_lower / stock_upper / status
- **bd_warehouse**：code(唯一) / name / manager_id / is_default / address / status
- **bd_supplier**：code(唯一) / name / contact / phone / address / tax_no / bank / account / credit_days / status
- **bd_customer**：code(唯一) / name / contact / phone / address / tax_no / bank / account / credit_limit / credit_days / status
- **bd_employee**：code / name / dept_id / position / mobile / entry_date / status

## 3. 采购管理
- **pur_apply**：apply_no / dept_id / applicant_id / need_date / status
- **pur_apply_item**：apply_id / goods_id / qty / need_date
- **pur_order**：order_no / supplier_id / order_date / status(草稿/待审/已审/部分入库/完成/关闭) / total_amount / tax_amount / audit_by / audit_at
- **pur_order_item**：order_id / goods_id / unit_id / qty / price / amount / tax_rate / inbound_qty
- **pur_inbound**：inbound_no / supplier_id / warehouse_id / order_id / inbound_date / status / total_amount
- **pur_inbound_item**：inbound_id / order_item_id / goods_id / qty / price / amount / batch_no
- **pur_return**：return_no / supplier_id / warehouse_id / return_date / status / total_amount
- **pur_return_item**：return_id / goods_id / qty / price / amount

## 4. 销售管理
- **sal_quotation**：quote_no / customer_id / quote_date / valid_until / status / total_amount
- **sal_quotation_item**：quote_id / goods_id / qty / price / amount
- **sal_order**：order_no / customer_id / order_date / status / total_amount / tax_amount / discount / audit_by
- **sal_order_item**：order_id / goods_id / unit_id / qty / price / amount / tax_rate / outbound_qty
- **sal_outbound**：outbound_no / customer_id / warehouse_id / order_id / outbound_date / status / total_amount
- **sal_outbound_item**：outbound_id / order_item_id / goods_id / qty / price / amount
- **sal_return**：return_no / customer_id / warehouse_id / return_date / status / total_amount
- **sal_return_item**：return_id / goods_id / qty / price / amount

## 5. 库存管理
- **inv_stock 库存**：warehouse_id / goods_id(联合唯一) / qty / locked_qty / available_qty / avg_cost
- **inv_stock_flow 流水**：warehouse_id / goods_id / biz_type / source_no / direction(1入/-1出) / qty / before_qty / after_qty / unit_cost / biz_time / operator_id
- **inv_transfer**：transfer_no / from_warehouse_id / to_warehouse_id / transfer_date / status
- **inv_transfer_item**：transfer_id / goods_id / qty / cost
- **inv_check**：check_no / warehouse_id / check_date / status / adjust_by
- **inv_check_item**：check_id / goods_id / book_qty / real_qty / diff_qty / cost
- **inv_alert**：warehouse_id / goods_id / alert_type(低于下限/高于上限/呆滞) / current_qty / threshold / handled

## 6. 财务管理
- **fin_receivable**：customer_id / source_type / source_no / amount / received_amount / unreceived_amount / bill_date / due_date / status
- **fin_payable**：supplier_id / source_type / source_no / amount / paid_amount / unpaid_amount / bill_date / due_date / status
- **fin_receipt**：receipt_no / customer_id / receipt_date / amount / method / account / operator_id
- **fin_receipt_item 核销**：receipt_id / receivable_id / writeoff_amount
- **fin_payment**：payment_no / supplier_id / payment_date / amount / method / account / operator_id
- **fin_payment_item 核销**：payment_id / payable_id / writeoff_amount
- **fin_expense**：expense_no / type / amount / expense_date / dept_id / applicant_id / status
- **fin_statement**：statement_no / party_type(客户/供应商) / party_id / period_start / period_end / begin_amount / current_amount / end_amount / status

## 7. 索引与约束
- `code`/`no` 建唯一索引；`is_deleted` 用部分索引
- 高频查询索引：`inv_stock(warehouse_id, goods_id)`、`inv_stock_flow(goods_id, biz_time)`、`fin_receivable(customer_id, status)`
- 明细表外键建索引；金额字段加 `CHECK (amount >= 0)`
